How I troubleshoot

When something fails, I narrow down which layer is wrong before I raise a defect, so the developer gets a diagnosis and not just a symptom.

  1. ReproduceExact steps, data and environment
  2. Browser DevToolsConsole errors, failed or slow network calls
  3. API layerReplay the request in Postman and check status, schema and payload
  4. Application logsFind the error or stack trace for that request
  5. DatabaseRun SQL to confirm what was actually stored
  6. ReportEvidence, likely cause and impact in JIRA

UI, API or data?

Comparing the three layers shows whether a bug is a display problem, a backend rule or a data integrity issue.

Automation failures

For failed test runs I use screenshots, traces and video to decide whether the product or the test is at fault.

Closing the loop

I retest with the developer, confirm the fix at the layer where it broke, and check nearby flows for regressions.
